# 此刻 Space 讨论原型

这是用于确认微信小程序页面和流程的浏览器原型，不是正式小程序。无外部依赖，无需安装。

## 打开

直接双击 `index.html`；也可以在仓库根目录执行：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory prototype
```

然后访问 `http://127.0.0.1:8765/`。若本机没有 Python，直接双击即可。可单独把 HTML 文件发给参会者，建议用电脑浏览器打开；手机可展示响应式布局。此地址仅本机可访问，尚未发布公网链接。

## 演示内容

- 首页标题为「此刻 Space · 播客联盟」，展示联盟简介和两处空间列表；先选空间、查看详情，再进入预约。
- 预约页展示从明天起 14 天：明天暂不可约，第 2—7 天可直接选择，一周以后提示联系客服。
- 时段使用一个范围选择器：在同一时间表内第一次点开始时间、第二次点结束时间，区间高亮；不再预设 1、1.5、2 小时时长。
- 价格只区分音频和视频，不区分大、小包间；管理员可在演示后台修改两类价格。
- Type-C 和 Lightning 支持多选，并提供无线麦克风、手机支架、补光灯、监听耳机和转接头等设备清单；更多人数需联系客服协助。
- 第一阶段不接微信支付。用户提交预约申请后显示「已提醒 @大漠妈 跟进」，联系运营付款；管理员确认收款后预约生效。
- 管理员可新增/移除禁约时段、确认人工收款、顺延或取消预约、调整音视频价格。
- 活动页分为即将举行和往期活动；即将举行的活动按人数上限报名，满员后停止报名。报名演示使用微信身份、手机号和报名人数。
- 服务页只有「录制空间」可进入，其他五项禁用并提示联系运营人工沟通。

## 边界

预约、报名、禁约时段、价格和咨询只存在当前浏览器内存，刷新清空；不跨设备同步。不是真实登录、微信支付、消息提醒、扫码、地图、退款、设备检测、云上传或管理后台。`@大漠妈` 仅为成功提示文案，不会真实发送通知。

场地名字来自功能清单；活动、房间配置和占用为示例。一寸金咖啡空间使用用户提供的“一寸金​.jpg”，住邦 2000 茶空间使用“栖源-茶空间.jpg”，品牌标志使用 `images/logo.jpg`；三张图片均已内嵌在 HTML 中，单文件离线分享仍可显示。初始示例价为音频 60 元/小时、视频 120 元/小时，可在管理员界面临时调整。请勿填真实个人资料或手机号。

主问题：活动 1.0 是否确认采用「联盟统一发布 + 多方提交合作需求」，把多方自助发布平台放到有真实需求后的版本？

## 会议结论待填

- 首页方向：已按「空间优先」调整。
- 预约窗口：明日起两周；明天暂不可约，第 2—7 天在线预约，一周以后联系客服。
- 首期付款：人工联系付款，不接微信支付。
- 活动：联盟发布；本轮增加人数上限和报名。
- 茶饮、人工退款、客服联系方式和通知责任人：待定。
- 决策人和日期：待定。

确定后保留结论，并按正式小程序工程重建。不要直接将本演示稿当生产代码发布。详见 `docs/小程序功能评审与分阶段开发建议.md`。
