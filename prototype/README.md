# 此刻 Space 讨论原型

这是用于确认微信小程序页面和流程的浏览器原型，不是正式小程序。无外部依赖，无需安装。

## 打开

直接双击 `index.html`；也可以在仓库根目录执行：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory prototype
```

然后访问 `http://127.0.0.1:8765/`。若本机没有 Python，直接双击即可。可单独把 HTML 文件发给参会者，建议用电脑浏览器打开；手机可展示响应式布局。此地址仅本机可访问，尚未发布公网链接。

## 演示内容

- 三种结构不同的首页：A 空间优先、B 时间优先、C 社区优先。底部箭头切换，URL 使用 `?variant=A/B/C`；输入框外左右方向键也可切换。
- 共享流程：空间、房间、录制类型、日期、连续时段、人数、接口、报价、模拟支付、预约、签到、结束、评价。
- 支付失败、时段冲突、取消申请与模拟退款结果。
- 活动展示、六大服务咨询，运营预览中的订单与咨询联动、示例活动发布。
- 评审控制栏可切换报价身份；「新会员」仅模拟已经取得资格，不含会员开通流程。

## 边界

订单、咨询、库存只存在当前浏览器内存，刷新清空；不跨设备同步。不是真实登录、微信支付、扫码、地图、提醒、退款、会员开通、设备检测、云上传或管理后台。

场地名字来自功能清单；活动、日期、房间配置和占用为示例。一寸金咖啡空间使用用户提供的“一寸金​.jpg”，住邦 2000 茶空间使用“栖源-茶空间.jpg”；图片已内嵌在 HTML 中，单文件离线分享仍可显示。音频 60 元/小时、视频 120 元/小时、音频新会员首小时 29.8 元、会员 9 折均用于讨论。茶饮套餐及结算不在原型中确定。请勿填真实个人资料。

主问题：首期是否采用「场地预约为主，活动和六大服务作辅助入口」？推荐 A，最终选择与业务规则由评审会确认。

## 本次验证

2026-09-16 在浏览器中检查了三种首页、桌面与窄屏布局，走通普通价预约、会员 54 元报价、29.8 元体验价展示、模拟支付、签到、结束和评价。已检查占用时段不可选、取消申请与模拟退款结果、服务咨询与运营跟进、示例活动发布，以及支付失败和时段冲突重选。JavaScript 语法检查通过，检查期间浏览器未报告脚本错误。

这些检查只证明本地原型交互；未进行微信真机、真实收退款、跨客户端并发、服务端权限或上线审核验证。
